# Ooru Kathe

Everything behind the Ooru Kathe reels (@oorukathe on Instagram, YouTube and the ಊರು ಕಥೆ Ooru Kathe Facebook page): one folder per video.

```
YYYY-MM-DD-place/
  research.md   facts, sources, fact-check notes
  script.md     voiceover script, on-screen text, cover hooks
  caption.md    Instagram/Facebook caption, YouTube title and description, links, stats
  photos/       images used in the reel
  voice/        recorded voiceover
  final.mp4     the finished reel (this is what gets uploaded)
```

New reel: copy `_template/` to `YYYY-MM-DD-place/` and fill it in.

Folders from 7-23 Nov 2026 were added from Instagram: they have the final video and caption, but not the research, script, photos or voice.

`video-tools/` holds reference video-editing skills (HyperFrames, motion-video-director). See `video-tools/README.md`.
