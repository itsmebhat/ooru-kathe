# Working in this repo

This is Praveen's Ooru Kathe content library. One folder per video, named `YYYY-MM-DD-place` (start from `_template/`).

- For every new reel, save the research, script, caption, photos, voice recording and final video in that reel's folder, and commit it.
- When Praveen says "share" a reel, upload `final.mp4` with the caption from `caption.md` to Instagram (@oorukathe), the ಊರு ಕಥೆ Ooru Kathe Facebook page (page id 1467259009804450) and YouTube Shorts. Public file link: `https://raw.githubusercontent.com/itsmebhat/ooru-kathe/main/<folder>/final.mp4`. Then write the post links back into `caption.md`.
- Keep files under 100 MB (GitHub's limit).
- Captions: hook, short story, this-or-that question, a share line, follow line, 3-5 hashtags (no #shorts on Instagram/Facebook), plain keywords last line. YouTube keeps #shorts.
